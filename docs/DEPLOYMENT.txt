RUN AND SHARE DRAINCHECK

Install Python 3.12 dependencies and restore the matching real datasets using
docs/INSTALLATION.md. A fresh Git checkout does not include the bulk datasets.

Local app, from its activated Python environment:
  python scripts/serve.py
  python scripts/serve.py --no-browser --port 8040
The API and built frontend are served at http://127.0.0.1:8040.

Windows launchers:
  Run_Sofia_App.cmd           Local app
  Run_Cloudflare_Demo.cmd     Temporary public link; keep this PC online

After frontend changes, install Node 22+ and pnpm, then run:
  pnpm install --frozen-lockfile
  pnpm test
  pnpm build
Restart the app after changing its build, backend or prepared datasets.

Temporary sharing: docs/CLOUDFLARE_TUNNEL_DEMO.md
Cloudflare hosting: docs/CLOUDFLARE_DEPLOYMENT.md

Keep original terrain and source data intact. Flood screening and scenarios
require matching 5 m rasters, water and river/stadium exclusions, their metadata,
green mask and vector indexes. Check /api/health and the relevant layer metadata
before sharing; terrain/spatial readiness alone does not verify every layer.
